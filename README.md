# Titanic Data Analysis with Python

### Project Overview
An exploratory data analysis (EDA) of the Kaggle Titanic dataset using Python to inspect missing values and analyze passenger survival demographics.

### Tech Stack
* **Python**
* **Pandas** (Data cleaning and inspection)
* **Seaborn & Matplotlib** (Data visualization)

### Key Insights
* **Missing Data:** Identified missing values in `Age` (177) and `Cabin` (687) columns.
* **Gender Breakdown:** Visualized survival rates confirming a significantly higher survival count for female passengers.
